ABN Lookup Automation for AU Leads

Verifying an ABN takes 30 seconds. Doing it for 500 leads takes 4 hours. Here's how to automate it.

The problem

If your sales pipeline is AU-focused, every lead needs an ABN lookup — to confirm the business is real, registered, and GST-active. The Australian Business Register (ABR) provides a free public API, but most sales teams do it manually, copy-pasting each company name into abr.business.gov.au and typing the result into a CRM.

For 50 leads/week, that's 25 minutes/week of soul-crushing data entry. For 500 leads/week, it's a part-time job.

The solution

An n8n workflow that takes a Google Sheet of company names, calls the ABR API for each, and writes back the ABN, entity type, GST status, and registration date.

Build time: 3-4 hours. Cost to run: A$0 (ABR API is free, n8n Cloud free tier covers 200 executions/mo). Or hire it built: A$500 fixed-price.

The walkthrough

  1. Trigger: Google Sheets — new row added to "Leads" tab
  2. ABR lookup: HTTP Request to https://abr.business.gov.au/json/AbnSearch.aspx with the company name as a search query
  3. Parse: Function node to extract ABN, entity type, GST status, registration date from the JSON
  4. Write back: Google Sheets — update the same row with the verified fields

Compliance (Privacy Act 1988)

The ABR data is public, but you're still collecting it. AU Privacy Act 1988 + APPs apply. Minimum to do this right:

  • Document the collection purpose in your privacy policy
  • Don't share the enriched data with third parties without consent
  • Keep an audit trail of when each lookup was run (the workflow already does this in n8n's execution log)

The catch

The ABR API is rate-limited. Free tier is 20 requests/minute, 1000/day. If you need more, you'll need a paid tier or to throttle the workflow. The 3-4 hour build includes a 1-second delay between requests — small enough to not trip the rate limit, large enough to not look like scraping.
