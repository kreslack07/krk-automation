ServiceM8 ↔ Google Calendar Two-Way Sync

Most tradies use ServiceM8 for job management but Google Calendar for personal scheduling. The two never agree, so the tradie's day has two versions: the "work day" in ServiceM8, and the "life day" in Google Calendar. This workflow unifies them.

Direction 1: ServiceM8 → Google Calendar

Trigger: ServiceM8 webhook — job status changes to "scheduled" or "active"

Action: Create or update a Google Calendar event with the job name, address, scheduled time, and customer name. Add the customer's phone as the event description so a tap-to-call works from the calendar.

Direction 2: Google Calendar → ServiceM8

Trigger: Google Calendar event created or updated (any calendar the tradie uses)

Action: If the event is a "personal" or "blocked" event (e.g., kids' school pickup, doctor's appointment), update the ServiceM8 schedule to block that time. Tradie never double-books.

Why this matters

The single biggest source of tradie frustration is "I forgot I had [personal thing] and now I can't make the job." This workflow makes that impossible — personal commitments show up in the ServiceM8 day, and work commitments show up in the personal calendar.

The catch

ServiceM8's webhook setup requires a "ServiceM8 API key" (free) and a public n8n webhook URL (n8n Cloud handles this; self-hosted needs ngrok or similar). Build time: 3 hours. Cost: A$0.
